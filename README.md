# Creative Kicks Media email assets

Images used by the Creative Kicks Media email signatures, served through jsDelivr:

https://cdn.jsdelivr.net/gh/mikey-jabs/email-assets@1.0/ckm-logo-tile.png

Files are pinned to a release tag. To change an image, replace the file, commit, and create a new tag (1.1, 1.2 and so on), then update the version in the signature HTML.

Social icons: Font Awesome Free brands, CC BY 4.0.
